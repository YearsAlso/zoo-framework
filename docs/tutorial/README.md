## 一个通用提示 {#log-level-tip}

本框架默认会在控制台打印框架自身的调度日志（每个 Worker 每轮的启停）。
首次上手时它会淹掉你自己的输出。**建议在教程期间把日志级别调到 `warning`**：

```json
{ "log": { "path": "./logs", "level": "warning" } }
```

把上面存成工作目录下的 `config.json` 即可。实测对比（5 秒运行）：

| 配置 | 输出行数 | 其中属于你的输出 |
|---|---|---|
| 默认 | 23 | 3 |
| `log.level: warning` | **3** | **3** |

> 默认级别过高是一个已知问题，在 issue #111 中跟踪（目标是默认就不吵）。
