|---|---|

## 与用户文档的边界

| | 用户侧（`docs/`） | 贡献者侧（`docs/contributing/`） |
|---|---|---|
| 读者 | 使用框架的人 | 改框架的人 |
| 关心 | 怎么用、边界在哪、怎么迁移 | 怎么构建、怎么测、怎么提 PR |
| 变更影响 | 对外可见的行为 | 内部实现与流程 |

**新增文档时请先判断它属于哪一侧**，然后放进对应目录。
