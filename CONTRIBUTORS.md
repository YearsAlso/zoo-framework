<a name="english"></a>
## 🇬🇧 English

Everyone whose work has landed in this repository. Entries are added **when a pull request
is merged** — there is nothing to sign up for, and no contribution is too small to appear
here.

| Contributor | Work |
|---|---|
| [@YearsAlso](https://github.com/YearsAlso) | Creator and maintainer — framework, docs, tooling, releases |

**You could be the next row.** [`docs/GOOD_FIRST_ISSUES.md`](docs/GOOD_FIRST_ISSUES.md)
lists self-contained tasks sized at 15–60 minutes, each with its file paths, acceptance
criteria and the result a user will see.

This file lists people who *write* the framework. People who *use* it are recorded
separately in [ADOPTERS.md](ADOPTERS.md), where every row is labelled verifiable or not —
this file follows the same rule and claims nothing it cannot back up.

<a name="中文"></a>
## 🇨🇳 中文

所有把工作合进本仓库的人。名单在**一个 PR 被合入时**添加 —— 不需要报名，也没有小到不值得
列出来的贡献。

| 贡献者 | 做了什么 |
|---|---|
| [@YearsAlso](https://github.com/YearsAlso) | 作者与维护者 —— 框架、文档、工具链、发布 |

**下一行可以是你。** [`docs/GOOD_FIRST_ISSUES.md`](docs/GOOD_FIRST_ISSUES.md) 里列着
15–60 分钟量级的自包含小活，每条都写明文件路径、验收标准，以及对使用者可见的结果。

本文件列出的是**写**框架的人；**用**框架的人记在 [ADOPTERS.md](ADOPTERS.md)，那里逐条标注
可核实与否 —— 本文件遵循同一口径，不写无法佐证的说法。
