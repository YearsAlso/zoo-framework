# config-resolution Specification

## Purpose
定义参数类解析的标识、回退与取值语义：解析缓存 MUST 以进程内唯一标识为键而非裸类名、别名 MUST 按声明顺序回退、已配置的假值 MUST 与"未配置"区分。该能力修复"同名参数类复用他人配置值"这一静默失效，并把别名回退与假值语义固定为可验证的契约。

## Requirements

### Requirement: 参数类解析缓存 MUST 以进程内唯一标识为键

参数类的解析结果 MUST 以在进程内唯一的标识为缓存键，MUST NOT 仅使用裸类名。定义位置不同的同名参数类 MUST 被解析为各自独立的配置，MUST NOT 复用彼此的解析结果。

#### Scenario: 同名参数类各自独立解析
- **WHEN** 两个定义位置不同的同名参数类各自声明一个取不同配置路径的参数项
- **THEN** 两个类各自解析到自己的配置路径对应的值，不出现其中一个复用了另一个的结果

#### Scenario: 同名参数类不会跳过解析
- **WHEN** 先导入并解析一个参数类，再导入另一个同名参数类
- **THEN** 第二个类仍执行自己的解析过程，而不是直接返回第一个类

#### Scenario: 同一参数类重复导入只解析一次
- **WHEN** 同一个参数类被多次导入
- **THEN** 其解析只发生一次，后续导入得到同一份已解析结果

### Requirement: 别名回退 MUST 按声明顺序生效

参数项 SHALL 可声明多个候选配置路径。解析 MUST 按"首选路径 → 别名（按声明顺序）→ 默认值"的顺序进行；仅当首选路径缺失时才回退到别名。

#### Scenario: 首选路径存在时不使用别名
- **WHEN** 参数项同时声明了首选路径与别名，且两者都已配置
- **THEN** 解析结果取自首选路径

#### Scenario: 首选路径缺失时回退到别名
- **WHEN** 参数项的首选路径未配置而其别名已配置
- **THEN** 解析结果取自该别名

#### Scenario: 全部候选缺失时使用默认值
- **WHEN** 参数项的首选路径与全部别名都未配置
- **THEN** 解析结果为该参数项声明的默认值

#### Scenario: 多个别名按声明顺序回退
- **WHEN** 参数项声明了多个别名且首选路径缺失
- **THEN** 按别名声明的先后顺序，取第一个已配置的候选

### Requirement: 已配置的假值 MUST 与缺失区分

解析 MUST 区分"配置了假值"与"未配置"。当配置项的值为 `False`、`0` 或空字符串时，解析结果 MUST 为该假值本身，MUST NOT 视为缺失而回退到别名或默认值。

#### Scenario: 配置为 False 时得到 False
- **WHEN** 一个布尔参数项被显式配置为 `False` 且其默认值为 `True`
- **THEN** 解析结果为 `False`，而非默认值 `True`

#### Scenario: 配置为 0 时得到 0
- **WHEN** 一个数值参数项被显式配置为 `0` 且其默认值非 0
- **THEN** 解析结果为 `0`，而非默认值

#### Scenario: 配置为空字符串时得到空字符串
- **WHEN** 一个字符串参数项被显式配置为空字符串且其默认值非空
- **THEN** 解析结果为空字符串，而非默认值
