## Purpose（本变更新增条款）

登记于容器的进程级管理器：复位归容器、状态归实例，类级入口只做转发。

## ADDED Requirements

### Requirement: 登记于容器的进程级管理器 MUST 由容器复位统一承载

经框架容器登记的进程级管理器，其可变状态 MUST 存于**容器持有的实例**，MUST NOT 以类属性或模块级全局另存一份。`framework_container().reset()` MUST 使这类管理器的全部状态回到初始（下次解析重建），测试基座 MUST NOT 为其保留容器之外的手工复位条目。若为兼容既有写法保留**类级读取入口**，该入口 MUST 转发到容器内的进程级实例（读取即解析），MUST NOT 指向另一份状态。管理器声明的线程安全归属 MUST 与实现一致：声明"实例自身保证"的，实例内部 MUST 自带互斥。

#### Scenario: 容器复位即彻底复位
- **WHEN** 向进程级管理器的注册表写入若干条目后执行容器 reset，再解析该管理器
- **THEN** 注册表为空——无需任何容器外的手工复位条目

#### Scenario: 类级读入口与实例状态同源
- **WHEN** 以类级写法读取注册表（兼容入口），又以实例写法读取同一注册表
- **THEN** 两者命中同一对象；容器复位后两者同步回到空表

#### Scenario: 声明与实现一致
- **WHEN** 检查声明为"实例自身保证"的进程级注册表类
- **THEN** 其读-改-写路径由实例内的锁保护，而非依赖容器串行
