## MODIFIED Requirements

### Requirement: 原生扩展 MUST 为可选依赖且缺失时显式失败

未安装原生扩展时，框架的既有功能 MUST 全部可用。执行契约在扩展缺失、契约版本不匹配或能力不满足时 MUST 在执行前明确拒绝（raise 或返回显式错误），MUST NOT 静默回退到 Python 实现。原生扩展的 Python 下界 MUST 独立于主包声明：可选扩展 MUST NOT 抬高主包的安装门槛，两侧下界不一致时 MUST 在文档中写明各自的下界，且在主包支持的下界解释器上安装该扩展 MUST 以显式错误结束，MUST NOT 产生"装上但不可用"的状态。

#### Scenario: 未安装扩展时请求原生任务被明确拒绝

- **WHEN** 在未安装原生扩展的进程中请求执行某个原生任务
- **THEN** 收到显式错误，指明缺失的是扩展而非该任务名

#### Scenario: 未安装扩展时既有功能不受影响

- **WHEN** 未安装扩展时使用普通 Worker、事件管线与状态机
- **THEN** 全部行为与不引入本变更时一致

#### Scenario: 契约版本不匹配被明确拒绝

- **WHEN** 已安装扩展的契约版本高于/低于框架支持的版本且不兼容
- **THEN** 请求原生任务被明确拒绝，错误注明两侧版本

#### Scenario: 扩展的下界独立于主包

- **WHEN** 比较主包与原生扩展各自声明的 Python 下界
- **THEN** 主包的下界不因扩展的下界而抬高；两者不同时，文档中能查到各自的下界与理由

#### Scenario: 在主包下界解释器上安装扩展显式失败

- **WHEN** 在主包支持的下界解释器上尝试安装原生扩展
- **THEN** 安装以显式错误结束（解释器版本不满足扩展的声明），不产生"装上但不可用"的状态
