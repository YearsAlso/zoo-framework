# cross-platform-io 规格 delta

## MODIFIED Requirements

### Requirement: 日志输出 MUST NOT 因控制台编码而整行丢失

系统向控制台或流输出日志时，MUST NOT 因输出目标不支持某个字符而丢弃整条日志。当某字符无法以目标编码表示时，系统 SHALL 以降级形式写出该字符，并 MUST 保留该条日志的其余内容。

框架自身的用户可见控制台输出（异常消息、日志消息、`print` 输出）MUST 为英文，使 GBK/CJK 代码页控制台不因框架自身的输出产生乱码。内部行注释与 docstring 的维护语言由仓库约定另行规定，不在本条款范围内。

#### Scenario: 非 UTF-8 输出目标上不丢失整行日志

- **WHEN** 向一个编码能力有限的输出目标写入含非 ASCII 字符的日志
- **THEN** 该条日志的其余内容被完整写出，不抛出异常，整行不消失

#### Scenario: 日志内容可被还原

- **WHEN** 某字符无法以目标编码表示而被降级写出
- **THEN** 该降级形式保留了原始码位信息，可被还原

#### Scenario: 字符可表示时原样写出

- **WHEN** 日志内容中的字符可被输出目标的编码表示
- **THEN** 该字符原样写出，不被降级

#### Scenario: 框架自身的控制台输出为英文

- **WHEN** 框架抛出异常或输出日志
- **THEN** 消息正文为英文（仅插值变量的 repr 可含非 ASCII）
- **THEN** 在 cp936（GBK）代码页控制台不含框架自身引入的不可编码字符
