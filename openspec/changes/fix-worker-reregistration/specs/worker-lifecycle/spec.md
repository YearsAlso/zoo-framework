## ADDED Requirements

### Requirement: Worker 同名重注册 MUST NOT 被实例缓存吞掉

以已存在的名称再次注册 Worker 时，新定义 MUST 真正生效，MUST NOT 让旧实例继续被按名取用。当以
同名注册一个**不同的类**时，注册表 MUST 作废该名称下由旧类延迟实例化出的缓存实例，使按名取用返回
新类的实例；以同名注册一个**不同的工厂**时 MUST 遵循同一语义；以同名注册**显式实例**时 MUST 以新
实例替换旧实例。以同名重复注册**同一个**类（定义未变）SHALL 幂等：MUST NOT 因重注册而丢失已实例
化的对象，元数据按最后一次注册更新。查找优先级（实例 → 工厂 → 类）与延迟实例化语义 MUST 保持
不变。

#### Scenario: 同名重注册新类后取用新类实例
- **WHEN** 以一个名称注册类 A 并取用其实例，随后以同一名称注册不同的类 B
- **THEN** 再次按名取用返回类 B 的实例，而非 A 的旧实例

#### Scenario: 同名重注册新工厂后取用新工厂产物
- **WHEN** 以一个名称注册工厂 F1 并取用其实例，随后以同一名称注册不同的工厂 F2
- **THEN** 再次按名取用返回 F2 的产物，而非 F1 的旧产物

#### Scenario: 同名重注册显式实例替换旧实例
- **WHEN** 某名称下已存在实例（延迟实例化得到或先前登记），再以同一名称登记一个新的实例
- **THEN** 按名取用返回新登记的实例

#### Scenario: 同名重注册同一个类保持幂等
- **WHEN** 以同一名称重复注册**同一个**类（可带新的元数据）
- **THEN** 已实例化的对象被保留，元数据按最后一次注册更新
